# First weapon sound palette

Unmodified source files, renamed for runtime use. Kenney CC0 notices are included
alongside them. Source packs remain in the ignored local assets directory.

| Runtime file | Original source under assets |
| --- | --- |
| gun.ogg | 2D assets/Desert Shooter Pack/Sounds/shoot-g.ogg |
| cannon.ogg | 2D assets/Desert Shooter Pack/Sounds/shoot-h.ogg |
| blast.ogg | 2D assets/Desert Shooter Pack/Sounds/explosion-a.ogg |
| rail.ogg | Audio/Sci-Fi Sounds/Audio/laserLarge_000.ogg |
| missile.ogg | Audio/Sci-Fi Sounds/Audio/thrusterFire_000.ogg |
| rumble.ogg | Audio/Sci-Fi Sounds/Audio/lowFrequency_explosion_000.ogg |

Playback normalizes source peaks, changes cannon pitch, and applies short gain
envelopes to bound duration. These are stylized effects; subjective mix and timbre
still need the author's listening/playtest. The files are not realistic recordings
of named weapons. Music remains separately controlled.
