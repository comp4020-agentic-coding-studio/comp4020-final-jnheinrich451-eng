# Emote artwork

Six unchanged PNGs from Kenney's Emote Pack 1.0, `PNG/Pixel/Style 1` in the
author's local `assets/2D assets/Emote Pack`. Distributed under CC0 according to
the included `License.txt`. Runtime UI labels map happy face to Hello, heart to
Thanks, question to Help, alert to Danger, exclamation to Follow me and stars to
Celebrate. Pixel scaling preserves the supplied artwork.
